# AYEBA Browser (Windows)

Navigateur desktop **Edge-like** pour Ayeba : vrais onglets Chromium (pas d’iframe), barre d’adresse, menu fonctionnel, page nouvel onglet Ayeba.

## Lancer

```bash
cd desktop/ayeba-browser
npm install
npm start
```

## Fonctions

- Onglets + `+` / Ctrl+T
- Nouvelle fenêtre / Ctrl+N
- Précédent / Suivant / Recharger / Accueil
- Omnibox : URL ou recherche Ayeba
- Favoris, Historique, Zoom, Recherche page (Ctrl+F), Imprimer, Effacer données
- Raccourcis JEMSA / SOMBATEKAONLE / DEVALPHA1 / TALA

## Build installateur

```bash
npm run dist
```

Sortie : `desktop/ayeba-browser/dist/`
